Download the latest installer from the **[Releases](https://github.com/oktovaaaaa/Flotil-App/releases/latest)** page:

- **[Flotil_1.1.2_x64-setup.zip](https://github.com/oktovaaaaa/Flotil-App/releases/latest/download/Flotil_1.1.2_x64-setup.zip)** *(Recommended · 4.2 MB)*

### Cara Install:
1. Unduh file `Flotil_1.1.2_x64-setup.zip` atau `.exe`.
2. Jika mengunduh file `.zip`, ekstrak file tersebut.
3. Jalankan `Flotil_1.1.2_x64-setup.exe`.
4. Ikuti instruksi setup wizard hingga selesai. Flotil akan langsung berjalan di bagian atas desktop Windows Anda.

## ✨ Fitur Utama
- 🏝️ **Dynamic Island Mode & Notch Mode:** Pilih mode tampilan Dynamic Island mengambang atau Notch klasik.
- 🎵 **Music & Synced Lyrics:** Kontrol media dan lirik lagu realtime (Spotify / Windows Media).
- ⏱️ **Pomodoro Focus Timer:** Pengatur waktu fokus & istirahat terintegrasi.
- 📅 **Calendar & Tasks:** Manajemen kalender dan to-do list harian dengan indikator visual.
- 📝 **Quick Notes:** Catatan cepat dengan proteksi hapus dan unduh berkas .txt.
- 📁 **Liquid File Shelf:** Tempat meletakkan file sementara dengan fitur auto-close otomatis saat file selesai disalin/dipindahkan.
- ⚡ **Device & System Vitals:** Pantau baterai, Wi-Fi, dan kontrol sistem dengan cepat.
- 🐬 **Idle Mascot Companion:** Animasi lumba-lumba interaktif saat laptop sedang santai.
- 🎨 **Light & Dark Mode:** Tampilan elegan yang menyesuaikan mode sistem Anda.
